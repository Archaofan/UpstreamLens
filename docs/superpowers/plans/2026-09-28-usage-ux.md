# Usage-first UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep a change actionable until explicitly handled, and make first-time source setup and check status easier to understand.

**Architecture:** Add a small, pure finding-queue selector over existing `LocalData`, then update the SwiftUI home, finding detail, and source editor to use it. Keep the existing Codable schema, GitHub client, local storage, and unsigned IPA pipeline.

**Tech Stack:** Swift 5.10, SwiftUI, XCTest, XcodeGen, GitHub Actions on macOS 26 / Xcode 26.6.

**Spec:** `docs/research/2026-09-28-usage-review.md`.

## Global Constraints

- Minimum iOS version stays 17.0; App, Widget, and App Group identifiers stay unchanged.
- Personal context remains in local JSON only; public GitHub access needs no account.
- First successful check establishes a baseline and reports no historical findings.
- Device installation and Widget App Group sharing remain pending device checks, separate from CI.

## Review Focus

- Opening an unread item moves it to viewed but retains it in the pending queue.
- Only handled findings move to history; a handled item can be restored.
- Priority sorting is deterministic for equal relevance and timestamps.
- An important-only filter does not mutate or hide history permanently.
- Existing backups retain the same JSON shape and all personal fields.
